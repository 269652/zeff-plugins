# Explorer (explorer-ext)

The file browser of this computer as a plugin. Generated by Zeff's `scripts/port-explorer.mts`.

- The screen is the view language: the database *Explorer* (under the page *Explorer*) has one view, `views/explorer.html`; the lambdas `explorer.screen` and `explorer.file` give it its data.
- The disk is read through Zeff's own bounded actions (`fs.list`, `fs.places`, `fs.read-text`, `fs.stat`): the built-in Explorer's path guard, never Zeff's own data folder. What changes something is a flow of the package (`explorer.save`, `explorer.make`, `explorer.import`, `explorer.import-folder`, `explorer.watch`, `explorer.unwatch`, `explorer.watch-mode`, `explorer.open-here`) — each needs the permission "api", which *Switch to the plugin* grants.
- Needs the Explorer's kernel service (the built-in Explorer on, or this plugin through its switch).
