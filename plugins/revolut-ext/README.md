# Revolut (revolut-ext)

The port of Zeff's built-in Revolut. Generated by Zeff's `scripts/port-revolut.mts` — change the built-in's core and generate it again.

- **Reading a statement**: the lambda `revolut.statement` fills the kernel's service `bank.statement` — the CSV export of Revolut
  (German or English) or another bank's CSV with a date, an amount and a text: its bookings (a pending one left for later) and the
  account. The reading is the built-in's own pure core (`src/plugins/revolut/core.ts`, bundled into `lambdas/_lib.mjs`): the same
  bookings, booking for booking.
- **What the kernel does with it** (`src/lib/bank/statements.ts`): the bookings kept in the bank, each once (`bank.import`, the
  cases' import button); a statement among your documents read by itself, once, and kept as a note of what it is.
- **Paying by RevTag** stays the kernel's todo action while this plugin is on (the built-in counts as there through it).
- **The switch** (*Switch to the plugin* on Revolut's card): this plugin on, the built-in off.
