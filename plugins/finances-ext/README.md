# Finances (finances-ext) — slice 1

The first slice of the port of Zeff's built-in Finances. Generated by Zeff's `scripts/port-finances.mts`.

- **The debt Kennzahlen** (Schuldenstand, Offene Schulden, Tilgungsrate, Schuldenfrei in, Schulden ohne Plan and the same for what you are owed): metrics
  of this plugin answered by the lambda `finances.metric` — the built-in's own plans (`src/plugins/finances/plans.ts`, bundled) worked out from the
  debts database's cells (the kernel's `db.cells`, by the fields' ids). Named "(Plugin)" beside the built-in's while both are on.
- **Not yet here** (still the built-in's — so there is no *Switch to the plugin* yet): the income and spending Kennzahlen (they read the bank statements),
  the formula functions `Schulden(@Person)`, `Forderungen`, `Rate`, the widgets, the overviews, the debts database's own rows, the debts from a promise.
