# Calendar (calendar-ext)

Zeff's calendar as a plugin. Generated by Zeff's `scripts/port-calendar.mts`.

- **The page** (`views/calendar.html`, an app view for the Calendar database): the built-in's toolbar and sidebar, the grid is the kit's `<schedule>` (day, week, month, agenda). Click opens the details (accept/dismiss a proposal, answer an invitation, delete — a series' occurrence, the following ones or all), dragging moves or resizes, dragging on free time opens a new appointment.
- **Lambdas** (read only): `calendar.screen`, `calendar.move`, `calendar.todos` (appointments to todos), `calendar.relations` (todos matched to appointments).
- **Flows** write: `calendar.save`, `.propose`, `.delete`, `.respond`, `.decide`, `.accept-todo-proposal`, `.move`, `.calendar`, `.todos`, `.relate` — through the kernel's `appointments.*` and `todos.*` actions (permission `api`).
- **Stays the kernel's**: the model (calendars, appointments, series), Outlook and Google Calendar's readers, Google's write access, the proposals queue, the Workspace's calendar database, the plugin API `calendar.*`, the todo action `calendar-entry`, the meetings for booking and the settings page.
- **Left out so far**: the dotted small month, changing the words of an existing appointment (drag it, or delete and make it again), repeating series and guests in the new-appointment form, keyboard shortcuts, the merged "Done" stripes, dashed proposals (they say "Proposed:").
