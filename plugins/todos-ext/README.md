# Todos screens (todos-ext) — slice 1

The Todos tab of Zeff as a plugin, in the view language. Generated by Zeff's `scripts/port-todos.mts`.

- The screen is the view language: the database *Your todos* (under the page *Todos*) has one view, `views/todos.html`; the lambda `todos.screen` gives it its data through the kernel's read `todos.rows`.
- What a click does is a flow of the package over the kernel's writes (`todos.set-status`, `todos.flag`, `todos.defer`, `todos.set-due`, `todos.add`): the same engine functions the built-in page calls. They need the flow's permission "todos".
- The todo engine (the todos, their operations, the settle hooks) stays Zeff's. The built-in Todos stays on until this is 1:1; both work on the same todos.
- **Not yet here:** the todo's panel (note, time, instruction, reply draft), sources and context, the actions, the omnibar filter, Activity, the recap, the Heute parts.
