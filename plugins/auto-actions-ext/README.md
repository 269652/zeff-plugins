# Auto actions (auto-actions-ext)

The AI step after the briefing, as a plugin. Generated by Zeff's `scripts/port-auto-actions.mts`.

- The review is the lambda `auto-actions.review` (the built-in's own logic over the kernel's todo reads); the flow `autoactions.review` runs it as the briefing's last step and puts the proposed actions on the todos.
- Its AI task is the row "Auto actions" of this plugin in Settings → AI. Your prompt page (System → Prompts → Auto-actions) works as before.
- The "Propose actions" button on a todo still uses the built-in's code until that is removed.
