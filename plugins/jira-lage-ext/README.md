# Jira briefing (jira-lage-ext)

The Board-Lage — "Analyse" on a Jira board — as a plugin. Generated by Zeff's `scripts/port-jira-lage.mts`.

- The flow `jira-lage.board-lage` is the Sync menu's step *Board briefing* (by hand): which tickets matter now (lambda `jira-lage.relevant`: the built-in's own rule), read fresh from Jira (the kernel's `jira.read-issues`), their comments kept (the store `comments` is the built-in's table), the boards' AI reviews, the AI blocks and the pipelines.
- The page *Board briefing* shows your boards and what the next run would read; its buttons start the flow.
- Stays Zeff's: the boards' Workspace databases and *Meine Lage* (made while Jira is synced), the ticket picker and "Assign to me" — they read the same tables with the plugin on.
