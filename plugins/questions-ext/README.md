# Questions (questions-ext)

Structured questions as a plugin. Generated by Zeff's `scripts/port-questions.mts`.

- The lambda `questions.ask` plans the queries, has Zeff run them (the kernel's `data.query`, over the views of `data.views`) and phrases the answer. The knowledge chat and the MCP tool `ask_structured` ask it while this plugin stands in for the built-in.
- The views over your data and their sensitivity labels stay Zeff's (the plugins that bring a view — the timeline — add it as before).
- Its AI task is the row "Structured questions" of this plugin in Settings → AI; your prompt pages (System → Prompts → Structured questions) work as before.
