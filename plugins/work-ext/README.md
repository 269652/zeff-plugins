# Code (work-ext)

The screens of the Code tab as a plugin. Generated by Zeff's `scripts/port-work.mts`.

- The screen is the view language: the database *Sessions* (under the page *Code*) has one view, `views/work.html`; the lambda `work.screen` gives it its data.
- The engine (workers, runs, the work host, the logs, the live sessions) is Zeff's: the lambda reads through `work.session-list` and `work.session-open`; what changes something is a flow of the package (`work.start`, `work.send`, `work.live`, `work.stop`, `work.archive`, `work.delete`) calling `work.session-*` — each needs the permission "api", which *Switch to the plugin* grants.
- Not in this slice (the built-in Code tab has it): the composer's options (repo, model, mode, effort, attachments, slash commands), the Changes and Preview panes, the branch switcher, the settings page, the Repos page.
