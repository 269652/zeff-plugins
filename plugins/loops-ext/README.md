# Open loops (loops-ext)

The engine of the open loops as a plugin. Generated by Zeff's `scripts/port-loops.mts`.

- Lambdas: `loops.all` (every loop), `loops.decision` (your word on one), `loops.closings` (closing by rule), `loops.ai-close` (the AI's closings) — the built-in's own rules, bundled, over the kernel's reads.
- Flows: `loops.decide`, `loops.close-by-rule`, `loops.close-by-ai` write what the lambdas worked out.
- What became of each loop is the built-in's table `loops_state`, adopted — nothing copied.
- The Today page, the chips in the inbox, the people's pages and the MCP tool `open_loops` stay Zeff's and read this plugin's answer.
