# Google Keep (keep-ext)

The port of Zeff's built-in Google Keep — all of it here, nothing of Keep's in Zeff's kernel. Generated by Zeff's `scripts/port-keep.mts`.

- **The scraper** is the driver lambda `keep.driver` (a lambda of kind *driver*: it runs with the account's automation Chrome, outside
  the sandbox — this plugin asks for `exec`). It is the built-in's own scraper: Keep opened in a fresh tab, what Keep's web app loads
  kept, the tab closed — nothing changes in Keep. **When Google changes Keep and the sync breaks**, mend it in the Studio (Lambdas →
  keep.driver) — you or the AI; the fix is kept in Zeff's database and wins over this one until you reset it.
- **Keeping the notes**: the store `notes` (the built-in's table `keep_notes`, adopted) — `keep.save-plan` works out what is new,
  changed and gone, as the built-in did.
- **The Google Keep database** in the Workspace: `keep.mirror-plan` gives its rows, the kernel's `db.mirror` writes what changed (the
  built-in's database goes on).
- **The sync** is the flow `keep.sync` — a step of the Sync menu in the built-in's place; by itself only while the automation Chrome runs.
  It may run the driver and use the store (its permissions `driver` and `store`, allowed when you switch).
- **The Google account** read: the plugin's setting *Google account* (taken over from the built-in when you switch).

**Switching:** Plugins → Google Keep Sync (built-in) → *Switch to the plugin*.
